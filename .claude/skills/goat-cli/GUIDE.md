# goat-cli — human guide

> The human doorway to the `goat-cli` skill. It points at the canonical source and does not restate it.

## When you're here

You want fabric, mesh or time health, whether data is flowing, who is on a goatnet and what they may do, topics and pub/sub, ACL assertions, data access or operator admin, through one binary.

## Where the real instructions live

- The goat user guide: [docs/goat-cli-book/src/](../../../docs/goat-cli-book/src/SUMMARY.md), served per goatnet and built by `docs/goat-cli-book/build.sh`.
- `goat --help`, `goat <command> --help` and `goat docs --markdown`: the command reference, generated from the binary.
- [docs/design/goat-cli-error-codes.md](../../../docs/design/goat-cli-error-codes.md): every error code; `goat explain <code>` reads it.
- A one-box goatnet to try it on: [docs/tutorials/00-goatlite.md](../../../docs/tutorials/00-goatlite.md).

## The agent's version

The `SKILL.md` beside this file is the same capability written for an agent: which verb to reach for, which verbs carry `--json`, and the gotchas.
