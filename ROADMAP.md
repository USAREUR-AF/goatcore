# Roadmap

This is a proposed order for the public engineering standards tracked below. Maintainers review priorities through the linked issues and [project board](https://github.com/orgs/USAREUR-AF/projects/8); the categories are sequencing guidance, not delivery dates.

Proposed: 2026-11-07. This draft needs maintainer review.

## Now

- Consistent CI safety checks across public repositories: action pins, token permissions, DCO and Dependabot ([#103](https://github.com/USAREUR-AF/goatcore/issues/103)).
- Shared issue and pull request templates, with repository-specific overrides ([#105](https://github.com/USAREUR-AF/goatcore/issues/105)).
- Governance documentation in every repository ([#109](https://github.com/USAREUR-AF/goatcore/issues/109)).

## Next

- OpenSSF Scorecard reporting ([#104](https://github.com/USAREUR-AF/goatcore/issues/104)).
- Contribution guides that match each repository's files and commands ([#106](https://github.com/USAREUR-AF/goatcore/issues/106)).
- Signed provenance and software bills of materials for releases and images ([#107](https://github.com/USAREUR-AF/goatcore/issues/107)).
- Changelogs for repositories that publish releases ([#108](https://github.com/USAREUR-AF/goatcore/issues/108)).

## Later

- Fuzzing the relay protocol and enrollment bundle readers ([#110](https://github.com/USAREUR-AF/goatcore/issues/110)).

## Propose a change

Use a feature request or [Discussions](https://github.com/USAREUR-AF/goatcore/discussions) for public proposals. Report vulnerabilities privately through [SECURITY.md](SECURITY.md). Security report details and unpublished fixes are not tracked on this public roadmap.
