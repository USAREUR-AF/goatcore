# Measurement register

Measurements taken on goatcore components: what was measured, how, and the
raw output, so anyone can rerun them. Each record is `M-NNN-<slug>.md`; its
scripts and raw output, when there are any, are under `M-NNN/`. The method
follows [ADR 1012](../adr/1012-load-testing-discipline.md).
