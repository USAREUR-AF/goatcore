# GB-033: promote refused a graduation step

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-033` is printed by `goatbuilder`. The same text offline: `goat explain GB-033` or `goatbuilder explain GB-033`.

## What it means

`goatbuilder promote` (the release ladder, ADR 1120/1125) refused: the record, the set, the ladder or the ref does not meet the rule the step names. Nothing graduates by itself; a refusal changes nothing.

## Why it happens

- the component is not ready (soak, live rows, convergence evidence) — the lines under the refusal name each blocker
- the component is a member of an open graduation set and must graduate with it
- a ref that is not digest-pinned (…@sha256:…), or a hotfix without --ack
- no open record for the component, or the record named does not exist or already graduated

## What to do

One line per step or alternative:

```text
goatbuilder promote status (what is open, soaking, ready)
goatbuilder promote readiness <component> (each blocker by name)
goatbuilder promote graduate-set <set> --ack '<name>' (when it is a set member)
```
