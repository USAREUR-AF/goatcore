# X-GH-003: GitHub rate-limited or forbade the call

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `X-GH-003` is an error of `gh` that goat and goatbuilder carry and interpret. The same text offline: `goat explain X-GH-003` or `goatbuilder explain X-GH-003`.

## What it means

HTTP 403 from the API: a rate limit, or a token without the scope.

## Why it happens

- many unauthenticated calls in a short time
- a token missing `read:packages` or `repo`

## What to do

One line per step or alternative:

```text
gh api rate_limit
gh auth refresh -s read:packages
```
