# GB-133: the edge or core host could not be probed for its ports

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-133` is printed by `goatbuilder`. The same text offline: `goat explain GB-133` or `goatbuilder explain GB-133`.

## What it means

the read-only probe (ops/ansible/peering-preflight.yml) returned no answer for a host, or `ss` could not list its sockets, so the ports were not checked. Not a pass.

## Why it happens

- the host is unreachable with the inventory the peering plays use (mesh down, wrong ansible_host, no SSH key)
- iproute2 (`ss`) is not installed on the host

## What to do

One line per step or alternative:

```text
cd ops/ansible && ansible -i inventory/peering-edges.ini <group> -m ping
install iproute2 on the host, then re-run phase 1
```
