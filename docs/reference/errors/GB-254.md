# GB-254: a file goatbuilder reads or writes cannot be read or written

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-254` is printed by `goatbuilder`. The same text offline: `goat explain GB-254` or `goatbuilder explain GB-254`.

## What it means

A verb reads or writes a file of the checkout or its state (a pin table, a schema, a record, an inventory, a play) and the operating system refused: the file is missing, unreadable, or its directory is not writable. The message names the file and the system's reason.

## Why it happens

- the file is not in this checkout, or -C names another one
- the file or its directory is not readable or writable by this user

## What to do

One line per step or alternative:

```text
ls -l <the file the message names>
goatbuilder -C <the right checkout> <verb>
```
