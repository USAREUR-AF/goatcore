# GB-214: the host firewall ruleset was not loaded or not confirmed

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-214` is printed by `goatbuilder`. The same text offline: `goat explain GB-214` or `goatbuilder explain GB-214`.

## What it means

Loading the rendered ruleset failed, or a fresh connection to the host did not succeed after it was loaded. A ruleset that was loaded is undone by the rollback timer the role armed before loading it.

## Why it happens

- the kernel refused the ruleset (nft -c failed), for example an nftables too old for a rule
- the new ruleset blocks the connection the controller makes, through a path the lockout check could not see (a jump host, a NAT between controller and host)
- systemd-run is not available on the host, so no rollback could be armed and nothing was loaded

## What to do

One line per step or alternative:

```text
wait goat_host_firewall_rollback_seconds, then: nft list table inet goat_host_firewall (the previous table is back)
read /etc/goat-host-firewall/ruleset.nft.new on the host and the play output
```
