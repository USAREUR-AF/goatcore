# GB-331: a standup phase failed

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-331` is printed by `goatbuilder`. The same text offline: `goat explain GB-331` or `goatbuilder explain GB-331`.

## What it means

A phase of goatbuilder standup exited non-zero. The row prints the phase, its label and its exit code; the run stopped there, and no later phase ran. The site is left partway through that phase.

## Why it happens

- the phase's own error, printed above the row (a play's failed task, a refused gate, a host that did not answer); the interpreted row under it names a catalog code when the output carries one

## What to do

One line per step or alternative:

```text
fix the cause, then resume: goatbuilder standup <environment> --site <site> --from <phase> (every phase is idempotent)
```
