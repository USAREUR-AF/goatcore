## What it means

rerun immediately before a change, a live phase-1 check (ports, slot list, core router, receive stores) did not pass, so nothing may change. SKIP is not a pass here.

## Why it happens

- another service took a port the plan expected free
- a slot was minted after the slot list was fixed
- the core router was replaced or stopped
