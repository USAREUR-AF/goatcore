# GB-130: a federation input is missing

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-130` is printed by `goatbuilder`. The same text offline: `goat explain GB-130` or `goatbuilder explain GB-130`.

## What it means

federate phase 1 (preflight) found inputs the later phases need that nothing declared and nothing could derive. Every missing input is listed with where to declare it. Nothing was measured, signed or deployed.

## Why it happens

- the deployment does not declare it (the edge group's group_vars, the peering's entry in goatbuilder.yaml peerings:, the inventory)
- the script avenue (peering-standup.sh) was run without exporting it; goatbuilder derives what it can, the script does not

## What to do

One line per step or alternative:

```text
declare each listed value where the line names it, then: goatbuilder federate <partner> --from 1 --to 1
export FED_<NAME>=... (one command only; an exported value always overrides what goatbuilder derives)
```
