# GB-320: a program the run starts could not be started

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-320` is printed by `goatbuilder`. The same text offline: `goat explain GB-320` or `goatbuilder explain GB-320`.

## What it means

A goatbuilder verb runs its phases and helpers as programs: bash for a phase's command, python3 for a step written in Python (the preflight, the slot recheck), and the helpers a step names (the core's candidate planner). The operating system refused to start one: it is not installed, not on PATH, or not executable. Nothing of that step ran.

## Why it happens

- bash or python3 is not installed on the machine goatbuilder runs on, or not on PATH
- a helper the step names is missing from the checkout, or has lost its executable bit

## What to do

One line per step or alternative:

```text
command -v bash python3 (install what is missing, then run the same command again)
git -C <checkout> status (restore a helper the checkout is missing)
```
