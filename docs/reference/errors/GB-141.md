# GB-141: our CA signing key cannot be resolved

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-141` is printed by `goatbuilder`. The same text offline: `goat explain GB-141` or `goatbuilder explain GB-141`.

## What it means

the CA private key phase 8 needs is missing, does not decrypt with the age identity, is not a private key, or does not match the CA certificate. The deployment keeps it at &lt;deploy.state_dir>/&lt;site>-ca/ca.key.age; preflight decrypts it in memory to compare and writes no plaintext.

## Why it happens

- the ca.key.age file is not on this machine
- the age identity (~/.config/age/keys.txt, or FED_AGE_IDENTITY) is not the one the key was encrypted to
- the key belongs to another CA than the certificate

## What to do

One line per step or alternative:

```text
restore <deploy.state_dir>/<site>-ca/ca.key.age, or set goat_federation_ca_key_age / FED_CA_KEY_AGE
export FED_AGE_IDENTITY=<the identity file the key was encrypted to>
```
