# GB-060: a standup input is required and not set

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-060` is printed by `goatbuilder`. The same text offline: `goat explain GB-060` or `goatbuilder explain GB-060`.

## What it means

A role or play the site's standup will reach asserts this variable, or reads it through `| mandatory`, and nothing the site supplies sets it: not group_vars, the inventory, host_vars, the play's vars, a role default, nor an extra var the plan passes. The scan lists every such input at once, before any host is touched.

## Why it happens

- the site's config surface was made from a reference goatnet and this key was not carried over
- the role gained a required input after the site was configured

## What to do

One line per step or alternative:

```text
set the variable in ops/ansible/group_vars/<group>/ (or the inventory)
goatbuilder doctor --site <site> (re-scan; every gap is listed)
```
