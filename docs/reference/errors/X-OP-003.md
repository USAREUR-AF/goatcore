# X-OP-003: a reference does not resolve to an item

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `X-OP-003` is an error of `op` that goat and goatbuilder carry and interpret. The same text offline: `goat explain X-OP-003` or `goatbuilder explain X-OP-003`.

## What it means

the vault, item or field named in an op:// reference does not exist, or this account cannot see it.

## Why it happens

- the item was renamed or moved to another vault
- the account lacks access to the vault

## What to do

One line per step or alternative:

```text
op item get '<item>' --vault <vault>
check refs/goat.refs in <owner>/goat-credentials for the current line
```
