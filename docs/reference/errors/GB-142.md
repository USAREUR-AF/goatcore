# GB-142: our federation signing key cannot be read

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-142` is printed by `goatbuilder`. The same text offline: `goat explain GB-142` or `goatbuilder explain GB-142`.

## What it means

FED_SIGNING_KEY names a file that does not exist, or whose content is neither 64 hex characters (the RFC 8032 seed) nor 44 base64.

## Why it happens

- goat_federation_signing_key or FED_SIGNING_KEY names the wrong path
- the file holds a PEM or a public key rather than the seed

## What to do

One line per step or alternative:

```text
set goat_federation_signing_key in group_vars/<edge group>/ to the file holding our Ed25519 seed
```
