# GB-112: sudo on a federation host wants a password

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-112` is printed by `goatbuilder`. The same text offline: `goat explain GB-112` or `goatbuilder explain GB-112`.

## What it means

The host answered over SSH, but `sudo -n true` failed: phase 3 reads the federation interface and the container runtime as root, the way the plays become root, and it never types a password.

## Why it happens

- the host's operator user is not NOPASSWD in sudoers (the baseline play sets it)
- ansible_become_user names a user this account cannot become without a password

## What to do

One line per step or alternative:

```text
run ops/ansible/mgmt-host-baseline.yml against the host once
set ansible_become: false for the host if its user can already read wg and the container runtime
```
