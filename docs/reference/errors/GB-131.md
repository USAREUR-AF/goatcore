# GB-131: a port this peering needs is already held on the edge

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-131` is printed by `goatbuilder`. The same text offline: `goat explain GB-131` or `goatbuilder explain GB-131`.

## What it means

the tunnel listen port (UDP) or the edge router listen port (TCP) is held on the edge host by something other than this peering's own interface or container. NetBird holds UDP 51820 on a mesh host, which is also the WireGuard default.

## Why it happens

- the tunnel listen port is the WireGuard default 51820 and NetBird's interface holds it
- another peering's edge router or interface already uses the port on a shared edge host

## What to do

One line per step or alternative:

```text
pin another port in the peering declaration: goatbuilder.yaml peerings: values: wg_listen_port / edge_listen_port
or set peering_wg_listen_port / goat_zenoh_edge_listen_port in group_vars/<edge group>/, then re-run phase 1
```
