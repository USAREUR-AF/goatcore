# GB-009: not a current main checkout

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-009` is printed by `goatbuilder`. The same text offline: `goat explain GB-009` or `goatbuilder explain GB-009`.

## What it means

releases and deploys run from the invoking checkout, and only a main checkout kept current with origin carries the pin that was merged. A branch or detached checkout can deploy a stale pin and verify green.

## Why it happens

- running from a feature-branch worktree
- running from a detached HEAD
- main is behind origin/main

## What to do

One line per step or alternative:

```text
git checkout main && git pull --ff-only origin main
goatbuilder doctor --all (the checkout row)
```
