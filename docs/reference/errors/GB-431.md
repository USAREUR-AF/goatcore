# GB-431: the NetBird group a machine's type declares cannot be minted at this site

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-431` is printed by `goatbuilder`. The same text offline: `goat explain GB-431` or `goatbuilder explain GB-431`.

## What it means

The type file declares the NetBird groups its node joins (`mesh_groups:`), and join-node phase 10 mints the node's key with exactly those. One of them is not a node-class tier a type may declare, or the site's taxonomy (ops/ansible/netbird_acl_taxonomy.yml) has no such group, so the declared ACL never made it, or no accept rule of the site's ACL (ops/ansible/netbird_acl_matrix.yml) lets PLATFORM-ADMIN reach it (ADR 1114 §2): a rule with PLATFORM-ADMIN as its source and the group as its destination, or the two either way round in a bidirectional rule (a rule that leaves `bidirectional` out is applied as bidirectional). A drop rule, a rule that names the group only as a source, and a qualified name such as HOST:BREAKGLASS (another scope's group, not this site's) are not counted. The run is refused at its first phase, before the node changes. Nothing was changed.

## Why it happens

- a goatlite, whose rendered taxonomy and ACL carry only INFRA, PLATFORM-ADMIN and DEVELOPER
- a site whose taxonomy declares the group but whose rules never name it
- a rule that names the group only as a source, a drop rule, or a qualified name such as HOST:BREAKGLASS
- a type file (an overlay's too) that declares a substrate or person tier such as INFRA

## What to do

One line per step or alternative:

```text
add the group to the site's taxonomy and an accept rule from PLATFORM-ADMIN to it to its rule intents, then run the declared ACL (standup phase 12) again
join-node --class <class> --to 9 (the phases before enrolment)
```
