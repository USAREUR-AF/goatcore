# X-OP-001: 1Password CLI is not signed in

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `X-OP-001` is an error of `op` that goat and goatbuilder carry and interpret. The same text offline: `goat explain X-OP-001` or `goatbuilder explain X-OP-001`.

## What it means

op needs a session for the account before it can resolve references.

## Why it happens

- no `op signin` in this shell
- OP_ACCOUNT names a different account than the one signed in

## What to do

One line per step or alternative:

```text
eval $(op signin) (OP_ACCOUNT=<account> for the team store)
goatbuilder doctor --credentials --all (the tool:op-session row)
```
