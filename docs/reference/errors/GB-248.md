# GB-248: the observability leg cannot run

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-248` is printed by `goatbuilder`. The same text offline: `goat explain GB-248` or `goatbuilder explain GB-248`.

## What it means

A site that declares has_obs_host: true stands up its observability host in a leg beside the core. --obs-only asked for that leg alone and there is none to run, or the leg's play (ops/ansible/utility-host-bootstrap.yml) is not in this tree. The message says which.

## Why it happens

- has_obs_host is not true, its group_vars or inventory host is missing (--obs-only)
- the checkout has no ops/ansible/utility-host-bootstrap.yml

## What to do

One line per step or alternative:

```text
goatbuilder standup <environment> --site <site> --skip-obs (stand up the site without its obs host)
declare has_obs_host: true, the <site>_obs_hosts group_vars and its inventory host, then run --obs-only
```
