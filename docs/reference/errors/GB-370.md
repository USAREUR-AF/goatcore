# GB-370: no usable peering directory URL or id was given

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-370` is printed by `goatbuilder`. The same text offline: `goat explain GB-370` or `goatbuilder explain GB-370`.

## What it means

goatbuilder federate directory needs the directory's base URL, from --url or FED_DIRECTORY_URL, as an http(s) URL; and a party or counterparty id as the directory accepts it, 2 to 16 of a-z, 0-9 and -. Nothing was requested.

## Why it happens

- neither --url nor FED_DIRECTORY_URL is set in this shell
- the URL has no https:// in front of it
- the id was typed with capitals, a slash or a dot

## What to do

One line per step or alternative:

```text
goatbuilder federate directory --url https://<directory host> ls
goatbuilder federate directory ls lists the ids the directory holds; copy one from there
```
