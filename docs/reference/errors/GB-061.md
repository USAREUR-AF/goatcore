# GB-061: a secret the standup templates is not in this environment

## What it means

A value the site supplies is lookup('env', NAME), a play or role the standup reaches uses it, and the declared secrets posture cannot supply NAME (ops/secrets/posture.py, ADR 1204).

## Why it happens

- the run is not under the site's secrets posture
- the posture's references file has no line for this name

## What to do

One line per step or alternative:

```text
run under your secrets posture: ops/scripts/with-secrets goatbuilder standup <env> --site <site>
add the reference for NAME to your .refs file
```
