# GB-326: a file of the checkout goatbuilder reads is not the YAML it should be

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-326` is printed by `goatbuilder`. The same text offline: `goat explain GB-326` or `goatbuilder explain GB-326`.

## What it means

goatbuilder read a file of the checkout (fleet-pins.yaml, the inventory's doors.yaml, a role's deploy-history.yml, ops/goatbuilder/teardown.yaml) and it does not parse as YAML, or not in the shape that file has. The message names the file and the parser's line and column. Nothing that reads it ran.

## Why it happens

- a bracket, quote or indentation error near the line named
- the file was edited by hand into another shape

## What to do

One line per step or alternative:

```text
fix the line the message names, then run the same command again
git -C <checkout> diff <the file> (what changed since the last commit)
```
