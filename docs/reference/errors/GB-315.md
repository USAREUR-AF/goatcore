# GB-315: a program a step ran gave output or an exit goatbuilder cannot use

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-315` is printed by `goatbuilder`. The same text offline: `goat explain GB-315` or `goatbuilder explain GB-315`.

## What it means

A step of a federate run started a program and reads its answer: the core's candidate planner prints a plan on stdout, and phase 1's preflight exits and writes a result whose ready verdict must agree with its exit. The program ran, but what it gave cannot be used: no plan on stdout, or an exit and a result that disagree or cannot be read. Its own words are in the message. Nothing after it ran.

## Why it happens

- the program failed before it gave its answer (its stderr is in the message)
- the program is a different version from the one this goatbuilder expects

## What to do

One line per step or alternative:

```text
read the program's own words in the message, fix what it names, then run the same command again
git -C <checkout> status (a helper the checkout changed or is missing)
```
