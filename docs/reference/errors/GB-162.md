# GB-162: one forwarder group names two forwarders

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-162` is printed by `goatbuilder`. The same text offline: `goat explain GB-162` or `goatbuilder explain GB-162`.

## What it means

The forwarder's peerings are rendered into its inventory group's group_vars, so every host in the group would relay every peering. Two peerings name the same group with different forwarder endpoints.

## Why it happens

- two forwarders declared without forwarder: group:, so both took the default peering_forwarders

## What to do

One line per step or alternative:

```text
give each forwarder its own group under forwarder: group:
```
