# GB-264: no recorded run matches

## What it means

goatbuilder show and runs diff name a run by its id, a prefix of one, or last, from the run records under &lt;state>/runs. None is recorded there, none starts with the prefix given, or several do.

## Why it happens

- no verb that drives hosts has run with this state directory (a --mock run writes no record)
- a mistyped id, or a prefix too short to name one run

One line per step or alternative:

```text
goatbuilder runs (the recorded runs, newest first)
give more of the run's id
```
