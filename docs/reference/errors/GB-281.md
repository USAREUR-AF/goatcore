# GB-281: the founder's management API token for mesh DNS is unset or unresolved

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-281` is printed by `goatbuilder`. The same text offline: `goat explain GB-281` or `goatbuilder explain GB-281`.

## What it means

join-node's mesh DNS step registers the joining site's nameserver group through the founder's management API, with the token in &lt;FOUNDER>_NB_API_TOKEN. After the secrets injector ran, the variable was empty or still held a secret store's reference, so the step was refused before it registered anything. The message names the variable, never its value.

## Why it happens

- the variable is not stored under the declared secrets posture
- the store's tool is not signed in, so with-secrets could not resolve the reference

## What to do

One line per step or alternative:

```text
python3 ops/secrets/posture.py hint <FOUNDER>_NB_API_TOKEN says where to store it
sign in to the declared store's tool, then re-run: goatbuilder join-node <environment> --site <site> --node <node> --class core --address <address> --from 13
```
