# GB-010: a Python dependency is missing

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-010` is printed by `goatbuilder`. The same text offline: `goat explain GB-010` or `goatbuilder explain GB-010`.

## What it means

the pins and intents render through PyYAML and jsonschema, and python3 cannot import one of them.

## Why it happens

- a fresh machine
- a venv that is not on PATH

## What to do

One line per step or alternative:

```text
pip install pyyaml jsonschema (or pipx/venv), then re-run; re-running is safe
```
