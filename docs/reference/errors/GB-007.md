# GB-007: a secret the play needs is not in your environment

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-007` is printed by `goatbuilder`. The same text offline: `goat explain GB-007` or `goatbuilder explain GB-007`.

## What it means

the play templates one or more variables from the environment and they are not set, so the run was refused before any host was touched.

## Why it happens

- the refs file for this component was never written
- the command was run without `op run`

## What to do

One line per step or alternative:

```text
put the lines for the named variables from <owner>/goat-credentials refs/goat.refs into .envrc.local.d/<file>.refs
OP_ACCOUNT=<account> op run --env-file=.envrc.local.d/<file>.refs -- <the same command>
```
