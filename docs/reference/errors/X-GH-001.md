# X-GH-001: GitHub returned 404

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `X-GH-001` is an error of `gh` that goat and goatbuilder carry and interpret. The same text offline: `goat explain X-GH-001` or `goatbuilder explain X-GH-001`.

## What it means

the repository, run, release or API path does not exist, or this account cannot see it.

## Why it happens

- a typo in the slug or id
- a private resource the account is not a member of

## What to do

One line per step or alternative:

```text
gh auth status
gh repo view <owner>/<repo>
```
