# GB-191: a value for confirmation 1 does not match

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-191` is printed by `goatbuilder`. The same text offline: `goat explain GB-191` or `goatbuilder explain GB-191`.

## What it means

At phase 5 or 6 a value given by flag or typed is not the one the files hold: their CA fingerprint is not their package's, their CA certificate does not carry that fingerprint, their verifying key is not 32 bytes of base64 or does not verify their half, a sovereign id is not a plain id or is not the declared counterparty, the agreement digest differs, or a package offered as the partner's new one is not well formed (its issued date more than 7 days after today's UTC date included), is not signed by the key bound for them, or is not the one --accept-partner-package names (ADR 1229; such a package is set aside as `theirs.incoming.json.refused-<UTC time>`), or, before any phase after 5, the partner's package on disk is not the one confirmed at phase 5, or the keys confirmed there do not hold for it (its CA fingerprint or the keyring's key changed; run phase 5 again), or the package confirmed at phase 5 is no longer at its place (no package held; run phase 5 again with them). The run stopped; at phase 5 no keyring was written and no package was placed, and at phase 6 the composed agreement is left for inspection.

## Why it happens

- a value was misheard or mistyped on the call
- the partner published a new package or CA after reading theirs aloud
- the two sides composed different agreements (their halves differ)
- at phase 6, the counterparty package is not the declared partner's (FED_COUNTERPARTY_ID): compose was given the two parties (--party) and composed nothing
- a package that is not the partner's current one, signed by another key or replayed, was offered as their new package

## What to do

One line per step or alternative:

```text
read the values back group by group with the partner, then run the same command again
goat federate diff <ours> <theirs> (names the field where two agreements differ)
```
