# GB-021: fastlane refused

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-021` is printed by `goatbuilder`. The same text offline: `goat explain GB-021` or `goatbuilder explain GB-021`.

## What it means

fastlane is the deliberate exception to the ladder and refuses an unpinned digest, an open graduation set, or an artifact whose rollback is not a pin revert.

## Why it happens

- the ref has no digest under repo.image_namespace
- a graduation set is open for the component

## What to do

One line per step or alternative:

```text
goatbuilder fastlane <component> --ref <ref> --dry-run
python3 ops/release/graduate.py status
```
