# GB-013: the image is not in the registry

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-013` is printed by `goatbuilder`. The same text offline: `goat explain GB-013` or `goatbuilder explain GB-013`.

## What it means

the tag's image was not found under repo.image_namespace, so no digest can be pinned.

## Why it happens

- crane is missing or unauthenticated — rc.sh resolves the digest with crane and discards its error, so a missing crane reads as the image not existing
- the build published under another name
- the package is private and the token cannot read it

## What to do

One line per step or alternative:

```text
brew install crane (then re-run; goatbuilder doctor --all: the tool:crane row says when it is present)
crane digest <repo.image_namespace>/<image>:<tag>
gh api /orgs/<owner>/packages/container/<image>/versions | head
```
