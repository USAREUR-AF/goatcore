# GB-052: that file is not a goatbuilder plan

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-052` is printed by `goatbuilder`. The same text offline: `goat explain GB-052` or `goatbuilder explain GB-052`.

## What it means

apply runs only a file plan wrote, which carries schema goatbuilder.plan/v1.

## Why it happens

- the wrong file was passed to apply
- the plan was edited by hand and its schema line lost

## What to do

One line per step or alternative:

```text
goatbuilder plan <verb> <component> … --out <file> (write it again)
```
