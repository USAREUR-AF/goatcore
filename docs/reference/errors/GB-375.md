# GB-375: the platform family has no file

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-375` is printed by `goatbuilder`. The same text offline: `goat explain GB-375` or `goatbuilder explain GB-375`.

## What it means

A type file accepts, or a machine declares (platform_family), a platform family that has no file in ops/goatbuilder/families/ or ops/goatbuilder/overlay/families/. The message lists the families there are. Nothing ran.

## Why it happens

- a misspelt family
- a model named where a family belongs (a type and a machine name families)
- the overlay that has the family's file is not in this tree

## What to do

One line per step or alternative:

```text
use one of the families the message lists
add ops/goatbuilder/families/<family>.yaml, or the overlay's own file
```
