# GB-147: a peering directory value is not usable

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-147` is printed by `goatbuilder`. The same text offline: `goat explain GB-147` or `goatbuilder explain GB-147`.

## What it means

FED_DIRECTORY_URL is not https, or it, FED_PACKAGE_URL, FED_COUNTERPARTY_ID or FED_CA_CERT holds characters outside a plain URL. Those values reach a command line, so the run refuses them.

## Why it happens

- an http:// directory address, or a value with spaces or quotes

## What to do

One line per step or alternative:

```text
set goat_federation_directory_url to the https:// address of the directory
```
