# GB-066: the site's declared end state cannot be derived or read

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-066` is printed by `goatbuilder`. The same text offline: `goat explain GB-066` or `goatbuilder explain GB-066`.

## What it means

endstate derives what a site should run from its own declarations (group_vars, the fleet pin table, the inventory) and the service catalog, then reads the site's hosts once over Ansible. One of those could not start, so nothing was graded.

## Why it happens

- the site name has no ops/ansible/group_vars/&lt;site>_hosts/ directory
- python3 or PyYAML is not installed on this machine
- the catalog file ops/goatbuilder/endstate/catalog.yaml does not parse

## What to do

One line per step or alternative:

```text
ls ops/ansible/group_vars/ (the site names this repository declares)
python3 ops/goatbuilder/endstate/endstate.py model <site> (the derived end state, without reading any host)
python3 ops/goatbuilder/endstate/endstate.py --self-test
```
