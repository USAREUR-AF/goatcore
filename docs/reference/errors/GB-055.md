# GB-055: a rollback with no --site would flip every goatnet

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-055` is printed by `goatbuilder`. The same text offline: `goat explain GB-055` or `goatbuilder explain GB-055`.

## What it means

the component is deployed on more than one goatnet and no --site was given; with no site the roll narrows to nothing, so it would flip every goatnet at once, prod included. Nothing was touched; the error lists the goatnets to choose from.

## Why it happens

- rollback (or plan rollback) was run on a component that spans several goatnets without --site
- the goatnet to roll back was left off the command

## What to do

One line per step or alternative:

```text
goatbuilder rollback <component> <N> --site <goatnet> (one of the goatnets the error names)
ops/scripts/rollback.sh <component> <N> --site <goatnet>
```
