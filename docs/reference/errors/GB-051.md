# GB-051: the plan request is incomplete or not planned yet

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-051` is printed by `goatbuilder`. The same text offline: `goat explain GB-051` or `goatbuilder explain GB-051`.

## What it means

plan writes deploy and rollback plans; a deploy plan needs --env, and a rollback plan reads a host ledger, so it has no fixture form.

## Why it happens

- plan deploy without --env
- a verb other than deploy or rollback
- plan rollback with --mock

## What to do

One line per step or alternative:

```text
goatbuilder plan deploy <component> --env <goatnet> --out <file>
goatbuilder plan rollback <component> --n 1 --out <file>
```
