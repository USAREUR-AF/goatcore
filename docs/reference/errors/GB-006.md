# GB-006: the door to the goatnet did not open

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-006` is printed by `goatbuilder`. The same text offline: `goat explain GB-006` or `goatbuilder explain GB-006`.

## What it means

the goatnet's management host was not reachable over the mesh, so the SSM door was tried, and it did not open.

## Why it happens

- no AWS credentials in the keychain for aws-vault (the profile in deploy.aws_profile)
- the SSM agent on the management host is not connected (TargetNotConnected)
- the door registry row is stale

## What to do

One line per step or alternative:

```text
ops/scripts/door-open.sh <goatnet> --status
aws-vault exec <profile> --no-session -- aws sts get-caller-identity
```
