# GB-075: goatbuilder could not replace its own binary

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-075` is printed by `goatbuilder`. The same text offline: `goat explain GB-075` or `goatbuilder explain GB-075`.

## What it means

The download was verified, but writing it next to the running binary or renaming it into place failed. The rename is atomic, so the binary in place is either the old one, whole, or the new one, whole.

## Why it happens

- the install directory is not writable by this user (a binary under /usr/local/bin installed with sudo)
- the disk is full

## What to do

One line per step or alternative:

```text
run the update as the user that installed goatbuilder (sudo goatbuilder update --site <site> for a system-wide install)
install by hand from get.<site>.<zone>/goatbuilder/, checking the .sha256 first
```
