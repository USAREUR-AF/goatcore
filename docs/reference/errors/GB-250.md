# GB-250: a joiner site names no founder

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-250` is printed by `goatbuilder`. The same text offline: `goat explain GB-250` or `goatbuilder explain GB-250`.

## What it means

A site whose vars.yml says goatnet_founder: false joins another site's goatnet, and seeds from it, so it must name that founder in join_founder_site.

## Why it happens

- join_founder_site is missing from the joiner's group_vars/&lt;site>_hosts/vars.yml

## What to do

One line per step or alternative:

```text
set join_founder_site: <founder site> in group_vars/<site>_hosts/vars.yml
```
