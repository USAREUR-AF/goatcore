# GB-376: the machine's platform family is not one its type accepts

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-376` is printed by `goatbuilder`. The same text offline: `goat explain GB-376` or `goatbuilder explain GB-376`.

## What it means

The machine declares its platform family (platform_family in host_vars, its inventory line or its group's group_vars), and the type it is to become accepts other families. The message names both, and the file the declaration is in. Nothing ran.

## Why it happens

- the role was given to the wrong machine
- platform_family is wrong for this machine

## What to do

One line per step or alternative:

```text
build the role on a machine of a family the type accepts
correct platform_family where the message names it
```
