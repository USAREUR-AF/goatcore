# GB-332: a join-node phase failed

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-332` is printed by `goatbuilder`. The same text offline: `goat explain GB-332` or `goatbuilder explain GB-332`.

## What it means

A phase of goatbuilder join-node exited non-zero. The row prints the phase, its label and its exit code; the run stopped there, and no later phase ran. The node is left partway through that phase.

## Why it happens

- the phase's own error, printed above the row (a play's failed task, a node that refused our key, a refused gate); the interpreted row under it names a catalog code when the output carries one

## What to do

One line per step or alternative:

```text
fix the cause, then resume: goatbuilder join-node <environment> --site <site> --node <node> --from <phase> (--dry-run prints the phase's command and the gate that proves it)
```
