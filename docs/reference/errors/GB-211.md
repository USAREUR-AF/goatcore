# GB-211: the host firewall override names a rule the baseline does not have, or is malformed

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-211` is printed by `goatbuilder`. The same text offline: `goat explain GB-211` or `goatbuilder explain GB-211`.

## What it means

The deployment's goat_host_firewall_override names a rule that is not in the baseline, names a fixed rule (loopback, established, invalid), uses a key other than drop, sources, ports, interface and reason, asks a fixed-expression rule for more than drop, or gives a reason holding a line break or another control character (the reason is written into the ruleset file). The whole override was refused and nothing was applied.

## Why it happens

- a misspelled rule name, or a peering rule named for an interface this host does not carry
- an attempt to add a new allow rule; only named baseline rules can be changed, and other-tcp / other-udp are the named rules for a service the host also runs

```text
python3 ops/ansible/roles/goat-host-firewall/files/goat-host-firewall-render.py --input <input.json> --list-rules (the names an override may use)
```
