# GB-323: a file the run writes outside the working folder cannot be written

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-323` is printed by `goatbuilder`. The same text offline: `goat explain GB-323` or `goatbuilder explain GB-323`.

## What it means

Some steps write outside the working folder: the back-out deletes the partner record it generated from the checkout, and init --side edge writes the edge half to the file --half-out names. That file could not be written or removed.

## Why it happens

- the checkout or the folder --half-out names is not writable by this user
- the disk is full, or the folder is on a read-only mount

## What to do

One line per step or alternative:

```text
check the folder the message names is writable, then run the same command again
```
