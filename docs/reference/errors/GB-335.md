# GB-335: a teardown failed

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-335` is printed by `goatbuilder`. The same text offline: `goat explain GB-335` or `goatbuilder explain GB-335`.

## What it means

goatbuilder teardown stops a site's services in reverse order, and one stop exited non-zero. The row names the component and the exit code. The services before it are down; nothing after it ran.

## Why it happens

- the stop's own error, printed above the row (a compose project or unit that did not stop, a host that did not answer)

## What to do

One line per step or alternative:

```text
fix the cause, then run the teardown again: goatbuilder teardown <environment> --site <site> --services (every stop is idempotent)
```
