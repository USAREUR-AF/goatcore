# GB-210: the host firewall baseline is missing a value it needs

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-210` is printed by `goatbuilder`. The same text offline: `goat explain GB-210` or `goatbuilder explain GB-210`.

## What it means

The host firewall baseline (roles/goat-host-firewall, rendered by its goat-host-firewall-render.py) could not build a ruleset, because a value it derives the rules from is missing or malformed. Nothing was applied.

## Why it happens

- goat_host_firewall_management_sources is empty, so SSH would be admitted from nowhere
- an edge run reached the role without its peering values (the play was not peering-wg.yml or peering-edge.yml)
- a port, address or interface name in the input is not one (a partner endpoint given as a name, an interface name over 15 characters)
- a management source is /0, the mesh interface is the host's uplink, or a br-\* bridge that is not docker's (a VXLAN segment bridge) exists while container-bridges is kept
- twice goat_host_firewall_confirm_timeout plus 15 s is not below goat_host_firewall_rollback_seconds
- the switch is false but the host still carries the baseline (/etc/goat-host-firewall/profile exists)

## What to do

One line per step or alternative:

```text
set goat_host_firewall_management_sources in the host's group_vars to the address or CIDR the deployment manages it from
python3 ops/ansible/roles/goat-host-firewall/files/goat-host-firewall-render.py --input <input.json> --list-rules (what the baseline derives)
```
