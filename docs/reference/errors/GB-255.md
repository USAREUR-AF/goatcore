# GB-255: nothing is declared for the environment

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-255` is printed by `goatbuilder`. The same text offline: `goat explain GB-255` or `goatbuilder explain GB-255`.

## What it means

The fixture's (or checkout's) declarations name no component for the environment asked for, or none by the name given, so there is nothing to read, plan or roll back.

## Why it happens

- a misspelt environment or component
- the environment declares no component yet

## What to do

One line per step or alternative:

```text
goatbuilder pins --check (what fleet-pins.yaml declares)
pass an environment and component the declarations hold
```
