# GB-244: the config file cannot be read

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-244` is printed by `goatbuilder`. The same text offline: `goat explain GB-244` or `goatbuilder explain GB-244`.

## What it means

goatbuilder reads the deployment's goatbuilder.yaml (or the file a verb was named) before anything else. It is not there, or it cannot be read.

## Why it happens

- the path is wrong, or -C names another checkout
- the checkout has no ops/goatbuilder/goatbuilder.yaml

## What to do

One line per step or alternative:

```text
goatbuilder -C <the deployment's checkout> <verb>
goatbuilder validate <path> (the file you meant)
```
