# GB-035: the goatnet's intent names no usable CA

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-035` is printed by `goatbuilder`. The same text offline: `goat explain GB-035` or `goatbuilder explain GB-035`.

## What it means

an intent has no ca_id, or one from which the CA's directory under &lt;deploy.state_dir> cannot be derived, so it cannot be signed.

## Why it happens

- a new goatnet whose intent was written without ca_id

## What to do

One line per step or alternative:

```text
add ca_id to the goatnet in ops/pins/fleet-pins.yaml, then: goatbuilder pins
```
