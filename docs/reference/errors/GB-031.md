# GB-031: an op:// reference in your shell is incomplete

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-031` is printed by `goatbuilder`. The same text offline: `goat explain GB-031` or `goatbuilder explain GB-031`.

## What it means

`op run` validates every environment variable whose value starts with op://, not only the env-file, and refuses the whole run when one has fewer than vault/item/field.

## Why it happens

- a variable exported from your shell profile for another project holds a two-part op:// reference

## What to do

One line per step or alternative:

```text
env | grep 'op://' (find the variable)
env -u <THAT_VAR> op run --env-file=… -- <command>
or complete the reference to op://<vault>/<item>/<field>
```
