# GB-012: the candidate's image build did not succeed

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-012` is printed by `goatbuilder`. The same text offline: `goat explain GB-012` or `goatbuilder explain GB-012`.

## What it means

after the tag was pushed, the image workflow did not appear, or ran and failed, so there is no image to validate.

## Why it happens

- the workflow is not triggered by this tag shape
- a build failure on the tagged commit

## What to do

One line per step or alternative:

```text
gh run list --workflow <component>-image.yml --limit 5
gh run view <id> --log-failed
```
