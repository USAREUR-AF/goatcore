# GB-184: the working folder or its lock cannot be made, taken or written

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-184` is printed by `goatbuilder`. The same text offline: `goat explain GB-184` or `goatbuilder explain GB-184`.

## What it means

A real run of `goatbuilder federate` keeps its lock and its run journal in the peering's working folder, and the allocation lock in the folder above it. One of them could not be created, locked or written, so the run did not start (or, mid-run, its journal is behind; the run says so in a failed `journal` row).

## Why it happens

- the working folder is not writable by this user (the default /var/lib/goat-federation needs root or a folder made for you)
- the disk is full or the folder is on a read-only mount

## What to do

One line per step or alternative:

```text
sudo install -d -o $USER /var/lib/goat-federation (or pass --work <a folder you own>)
check free space where the working folder is
```
