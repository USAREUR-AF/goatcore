# GB-296: a site turned on the audit spool, which is not built

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-296` is printed by `goatbuilder`. The same text offline: `goat explain GB-296` or `goatbuilder explain GB-296`.

## What it means

A site set audit_subscriber_spool_enabled: true. The spooling audit subscriber a phone site needs (docs/design/island-mode-audit-spool.md) is designed but not built, so there is nothing to deploy for it. The audit-subscriber role stopped before it changed anything.

## Why it happens

- a phone site's group_vars set audit_subscriber_spool_enabled: true before the spool exists

## What to do

One line per step or alternative:

```text
set audit_subscriber_spool_enabled: false in that site's group_vars: the end state then reports the site's own statement that its fabric has no audit
```
