# GB-145: the core certificate would not name every address the edge dials

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-145` is printed by `goatbuilder`. The same text offline: `goat explain GB-145` or `goatbuilder explain GB-145`.

## What it means

FED_CORE_SAN does not cover an address the edge's deployment.yml dials. A core certificate without that SAN fails name verification, and nothing is logged at INFO when it does.

## Why it happens

- an endpoint was added to group_vars/&lt;edge group>/deployment.yml after FED_CORE_SAN was set by hand

## What to do

One line per step or alternative:

```text
unset FED_CORE_SAN and let goatbuilder derive it from deployment.yml, or add the missing address
```
