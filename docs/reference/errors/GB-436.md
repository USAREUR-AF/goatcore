# GB-436: the declared secrets posture keeps no copy the bootstrap token can be read back from

## What it means

Standup phase 11 switches the bootstrap NetBird token on only after the token is stored under the declared secrets posture and read back (ADR 1274). The posture in force keeps no such copy: openbao, vaultwarden and custom hold references this repository cannot write, and env stores nothing. Phase 11 stays the manual step under it. Nothing was changed.

## Why it happens

- secrets.store is openbao, vaultwarden, custom or env
- under 1password, the identities registry declares no 1Password item for the bootstrap identity
