# GB-240: a federation switch names no choice it has

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-240` is printed by `goatbuilder`. The same text offline: `goat explain GB-240` or `goatbuilder explain GB-240`.

## What it means

Two variables choose how a peering run works: FED_VERBS who runs the federation verbs (goatbuilder, in process, the default; or goat), and FED_MEASURE where phase 3 measures (ssh, the default; or here). Any other value is refused, as peering-standup.sh refuses it, so a misspelling cannot choose a different path on each avenue.

## Why it happens

- FED_VERBS is set to something other than goat or goatbuilder
- FED_MEASURE is set to something other than ssh or here

## What to do

One line per step or alternative:

```text
unset FED_VERBS and FED_MEASURE (the defaults)
FED_VERBS=goat goatbuilder federate <partner> (the verbs run in goat)
FED_MEASURE=here goatbuilder federate <partner> (phase 3 measures the machine the run is on)
```
