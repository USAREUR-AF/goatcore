# GB-144: the federation declaration or the profile is missing or wrong

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-144` is printed by `goatbuilder`. The same text offline: `goat explain GB-144` or `goatbuilder explain GB-144`.

## What it means

the goat context has no federation.toml, it has no valid sovereign_id or it declares a measured capability, or the profile certificate or CA bundle is missing.

## Why it happens

- `goat profile init` was not run for this context, or ran as another user (sudo -E keeps HOME)
- federation.toml was not written, or declares transports, fabric_version, fabric_fips_image or pqc_capable

## What to do

One line per step or alternative:

```text
goat profile init <bundle.cbor>
goat federate init (prints the declaration template when it is absent)
```
