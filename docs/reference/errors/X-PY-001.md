# X-PY-001: a Python module is missing

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `X-PY-001` is an error of `python` that goat and goatbuilder carry and interpret. The same text offline: `goat explain X-PY-001` or `goatbuilder explain X-PY-001`.

## What it means

python3 could not import a module a script needs.

## Why it happens

- a fresh machine or a venv not on PATH

## What to do

One line per step or alternative:

```text
pip install <module> (pyyaml, jsonschema are the usual two)
a script Ansible runs on the control node uses ansible_playbook_python, which carries PyYAML; a task that still calls bare python3 should too
```
