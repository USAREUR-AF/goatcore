# GB-011: only a repository admin may nominate a release candidate

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-011` is printed by `goatbuilder`. The same text offline: `goat explain GB-011` or `goatbuilder explain GB-011`.

## What it means

the GitHub login in use does not hold the admin role on the repository; the rc-validate workflow deletes a tag pushed by anyone else (ADR 1173).

## Why it happens

- gh is logged in as a different account
- the account is a maintainer, not an admin

## What to do

One line per step or alternative:

```text
gh auth status
ask a repository admin to push the tag, or to grant the role
```
