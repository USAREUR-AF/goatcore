# GB-276: --mock was given to a verb that reads the checkout

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-276` is printed by `goatbuilder`. The same text offline: `goat explain GB-276` or `goatbuilder explain GB-276`.

## What it means

--mock runs a verb against a fixture directory instead of hosts. Only the verbs that drive or read hosts take one (the message lists them). This verb reads the checkout itself, so a fixture it was named would have been ignored, and the run would have reported on files the person never pointed it at. Nothing ran.

## Why it happens

- --mock given to a verb that reads the checkout, such as pins, validate or doctor

## What to do

One line per step or alternative:

```text
drop --mock: the verb reads the checkout (-C <dir> names another one)
goatbuilder --mock <fixture> <verb> with one of the verbs the message lists
```
