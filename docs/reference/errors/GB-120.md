# GB-120: a peering names a partner with a reserved word

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-120` is printed by `goatbuilder`. The same text offline: `goat explain GB-120` or `goatbuilder explain GB-120`.

## What it means

A word of `goatbuilder federate` (init lint compose diff verify apply help status plan deploy test allocate backout rotate) can never name a partner: `goatbuilder federate <word>` runs that step, so the peering could never be run by name.

## Why it happens

- a peerings entry's `with:` is one of the reserved words

## What to do

One line per step or alternative:

```text
name the partner by its sovereign id in goatbuilder.yaml peerings: with:
```
