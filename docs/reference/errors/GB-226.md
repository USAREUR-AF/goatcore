# GB-226: our package for the counterparty could not be withdrawn from the directory

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-226` is printed by `goatbuilder`. The same text offline: `goat explain GB-226` or `goatbuilder explain GB-226`.

## What it means

The back-out asks the peering directory to delete /v1/parties/&lt;us>/packages/&lt;partner>, signed by our bound key. The directory refused or could not be reached. This is a warning: a listing grants nothing, and the peering's hosts are already clean. Our single entry and every other party's entry are never touched.

## Why it happens

- FED_SIGNING_KEY is not set, or is not the key the directory binds to us
- the directory is unreachable

## What to do

One line per step or alternative:

```text
python3 ops/federation/standup/directory_withdraw.py --url <directory> --us <us> --them <partner> --key <signing key>
```
