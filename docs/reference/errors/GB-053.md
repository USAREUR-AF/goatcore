# GB-053: the plan no longer matches the tree

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-053` is printed by `goatbuilder`. The same text offline: `goat explain GB-053` or `goatbuilder explain GB-053`.

## What it means

apply recomputed the plan's decisions and at least one moved since it was written; it names each, and runs nothing.

## Why it happens

- main's declaration or the pins file changed since the plan
- a newer deploy or rollback moved the rollback target
- the plan is old

## What to do

One line per step or alternative:

```text
goatbuilder plan <same arguments> --out <file>, review it, then goatbuilder apply <file>
```
