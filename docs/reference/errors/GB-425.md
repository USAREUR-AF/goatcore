# GB-425: no model of a family the type accepts delivers the encryption it requires

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-425` is printed by `goatbuilder`. The same text offline: `goat explain GB-425` or `goatbuilder explain GB-425`.

## What it means

A type file requires an encryption scope (`encryption: root`), and it accepts a platform family none of whose models' entries delivers that scope (each model's `encryption.scope` in ops/goatbuilder/families/&lt;family>.yaml). A model that is only listed, or whose scope is unknown, delivers nothing. The message names the family and each model's scope. Nothing ran.

## Why it happens

- the type accepts a family whose models encrypt a data volume, not the root
- the family lists its models' names with no entry for each
- a model's entry has the wrong scope

## What to do

One line per step or alternative:

```text
accept only families a model of which delivers the scope
write each model's entry, with the scope its preparation delivers, citing its source
```
