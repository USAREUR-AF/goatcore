# GB-414: a machine lacks a value its type needs from the site

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-414` is printed by `goatbuilder`. The same text offline: `goat explain GB-414` or `goatbuilder explain GB-414`.

## What it means

A type file names `inputs`: values of the site's configuration a machine of the type needs, each an Ansible variable read where Ansible would for that machine (its host_vars, its inventory line, its group's group_vars, group_vars/all, the [group:vars] sections). The machine has the variable unset, or set to the role's placeholder (for network-jump, herd_connector_image is PENDING until an image is supplied). join-node refuses before any phase, a dry run too; standup refuses before any phase of a run that reaches phase 14; doctor --target shows the row. Nothing on the machine was changed.

## Why it happens

- the variable was never set for the site
- it is set to the role's placeholder

## What to do

One line per step or alternative:

```text
set the variable in ops/ansible/group_vars/<the machine's group>/, as the message and the type file's why say
```
