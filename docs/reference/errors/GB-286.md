# GB-286: a joining site has no leaf-cert manifest join-node can read

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-286` is printed by `goatbuilder`. The same text offline: `goat explain GB-286` or `goatbuilder explain GB-286`.

## What it means

join-node mints a joining site's router and service leaves from the site's manifest (ops/enrollment/manifests/&lt;site>-certs.yaml, with mint-site-certs.sh) and stages them onto the node before the data router. The manifest is missing, or is not readable YAML, so the plan was refused before any phase ran.

## Why it happens

- the site's manifest was never written
- the manifest has a YAML error

## What to do

One line per step or alternative:

```text
cp ops/enrollment/manifests/TEMPLATE-certs.yaml ops/enrollment/manifests/<site>-certs.yaml, then re-thread every value for the site: its URI SANs name this goatnet
ops/scripts/mint-site-certs.sh <site> --dry-run prints what the manifest mints, and names a YAML error
```
