# GB-325: flags given to a federate stage do not go together, or one they need is missing

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-325` is printed by `goatbuilder`. The same text offline: `goat explain GB-325` or `goatbuilder explain GB-325`.

## What it means

A federate stage was given flags it cannot take together (--accept with --recheck, --recheck with --mock or --no-live, --side without the files that side reads or writes), a flag without the one it needs (--work for status without the partner, init --over-ssh without -C), or a flag naming something the saved plan does not hold (--accept &lt;check>). Nothing ran.

## Why it happens

- a command line put together from two different runs' flags

## What to do

One line per step or alternative:

```text
run the stage with the flags the message names, apart where it says to run them apart
goatbuilder federate <stage> --help
```
