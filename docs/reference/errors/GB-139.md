# GB-139: several core router containers were found

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-139` is printed by `goatbuilder`. The same text offline: `goat explain GB-139` or `goatbuilder explain GB-139`.

## What it means

more than one running container qualifies as the core router, and preflight, like phase 3, will not choose among them.

## Why it happens

- an old and a new core router run side by side
- two stacks on one host both carry a \*-zenoh-router name

## What to do

One line per step or alternative:

```text
export FED_ROUTER_CONTAINER=<name or ID of the core router>
```
