# GB-251: no SSH user is declared for a new machine

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-251` is printed by `goatbuilder`. The same text offline: `goat explain GB-251` or `goatbuilder explain GB-251`.

## What it means

join-node reaches a new machine as the project's declared SSH user before anything is installed on it. The checkout declares none, and no name is right for every project's machines, so a real run refuses (a dry run plans with a placeholder).

## Why it happens

- deploy.ssh_user (or lite.ssh_user) is not set in goatbuilder.yaml

## What to do

One line per step or alternative:

```text
set deploy.ssh_user in ops/goatbuilder/goatbuilder.yaml
goatbuilder join-node ... --dry-run (plans without it)
```
