# GB-354: the env store holds none of a joining site's shared secrets

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-354` is printed by `goatbuilder`. The same text offline: `goat explain GB-354` or `goatbuilder explain GB-354`.

## What it means

join-node's phase 3 takes a joining site's shared values from its founder. Under the env store nothing persists, so it cannot write them: each joiner name must already be exported in the shell that runs join-node. One or more are not. Nothing was written.

## Why it happens

- the declared store is env (GOAT_SECRET_STORE=env or secrets.store: env)

## What to do

One line per step or alternative:

```text
export each named variable with the founder's value in this shell, then resume with --from 3
declare a store that persists (secrets.store in goatbuilder.yaml; docs/design/pluggable-dependencies.md)
```
