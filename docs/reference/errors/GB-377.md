# GB-377: a play the machine type converges with is not in this tree

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-377` is printed by `goatbuilder`. The same text offline: `goat explain GB-377` or `goatbuilder explain GB-377`.

## What it means

A type file may name a play of another repository or a private overlay, so a public clone reads and plans every type. A run needs the play. The message names it and where it comes from. Nothing ran on the machine.

## Why it happens

- the run is from a public clone, and the play is in an overlay or another repository
- the tree was assembled without the repository that has the play

## What to do

One line per step or alternative:

```text
run from a tree assembled with the repository or overlay the message names
stop before the phase that needs it, as the message says
```
