# GB-054: adopt could not create its worktree

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-054` is printed by `goatbuilder`. The same text offline: `goat explain GB-054` or `goatbuilder explain GB-054`.

## What it means

adopt --yes writes its declarations into a fresh worktree of origin/main beside the checkout; git refused to create it.

## Why it happens

- origin/main is not fetched
- a branch or directory of that name already exists

## What to do

One line per step or alternative:

```text
git fetch origin main
git worktree list (remove a stale adopt worktree)
```
