# GB-252: the partner is declared on several environments

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-252` is printed by `goatbuilder`. The same text offline: `goat explain GB-252` or `goatbuilder explain GB-252`.

## What it means

The same partner is declared as a peering on more than one environment in goatbuilder.yaml peerings:, so the command cannot tell which peering it is about.

## Why it happens

- one partner is peered from two environments, and --env was not given

## What to do

One line per step or alternative:

```text
pass --env <environment> (the environments are named in the message)
```
