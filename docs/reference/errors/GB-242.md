# GB-242: the command line does not parse

## What it means

The arguments do not make a command goatbuilder knows: a required argument is missing, a value is not one the option takes, two options that exclude each other were both given, or the verb is unknown. Nothing ran.

## Why it happens

- a required argument or subcommand was left out
- an option was given a value it does not take
- two options that exclude each other were given together
- a misspelt verb
