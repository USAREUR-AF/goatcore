# GB-435: only a founder site mints the bootstrap NetBird identity

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-435` is printed by `goatbuilder`. The same text offline: `goat explain GB-435` or `goatbuilder explain GB-435`.

## What it means

Standup phase 11 mints the goatnet's bootstrap NetBird service user and its token (ADR 1274) only on a site whose group_vars declare goatnet_founder: true. This site does not declare it, or declares false. A joining site's NetBird users and tokens replicate from its founder, so a mint there would add a second admin identity to the shared account. Nothing was changed.

## Why it happens

- the site's group_vars leave goatnet_founder unset (elsewhere it defaults to true; here it must be stated)
- the site is a joining site

## What to do

One line per step or alternative:

```text
on a founder site: add goatnet_founder: true to group_vars/<site>_hosts/vars.yml and run phase 11 again
on a joining site: the founder's standup mints the identity; the joiner takes the founder's token
```
