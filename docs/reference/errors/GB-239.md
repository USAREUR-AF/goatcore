# GB-239: a flag that does not apply to the federation verb it was given to

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-239` is printed by `goatbuilder`. The same text offline: `goat explain GB-239` or `goatbuilder explain GB-239`.

## What it means

The six federation verbs (init, lint, compose, diff, verify, apply) read only the files they are named and the party's context, and run for real. --mock, -C/--repo (except for init --over-ssh) and -o/--output choose things they do not read; --over-ssh and its host flags belong to init alone. A run with one where it does not apply is refused rather than the flag ignored.

## Why it happens

- --mock, -C/--repo or -o/--output given to a federation verb
- --over-ssh or its host flags given to a verb other than init, to a plan or to a peering run

## What to do

One line per step or alternative:

```text
drop the flag; the verbs take --json for a JSON report
goatbuilder -C <repo> federate init --over-ssh <peering> (the one verb that reads a checkout)
FED_MEASURE=ssh goatbuilder federate <partner> (a peering run measures phase 3 over SSH)
```
