# GB-111: a federation host did not answer over SSH

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-111` is printed by `goatbuilder`. The same text offline: `goat explain GB-111` or `goatbuilder explain GB-111`.

## What it means

Before measuring anything, phase 3 runs `true` on the edge and on the core over SSH, with the inventory's connection settings and the plays' privilege escalation. That command failed, so nothing was measured. The message carries the ssh command it ran.

## Why it happens

- this machine is not on a network that reaches the host (mesh profile, door or jump host)
- the host refused the key (see X-SSH-001)
- the host key changed (see X-SSH-003)
