# GB-049: the acceptance assay cannot run here

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-049` is printed by `goatbuilder`. The same text offline: `goat explain GB-049` or `goatbuilder explain GB-049`.

## What it means

assay derives the site's values from its group_vars and runs ops/validation/run-acceptance.py with python3; one of those could not start, so nothing was probed.

## Why it happens

- the site name has no ops/ansible/group_vars/&lt;site>_hosts/vars.yml, or --values names no file
- python3 or PyYAML is not installed
- the runner stopped with an error rather than a verdict

## What to do

One line per step or alternative:

```text
ls ops/ansible/group_vars/ (the site names this repository declares)
pip3 install pyyaml
python3 ops/validation/run-acceptance.py --self-test
```
