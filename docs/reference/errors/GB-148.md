# GB-148: the federation working directory is not writable

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-148` is printed by `goatbuilder`. The same text offline: `goat explain GB-148` or `goatbuilder explain GB-148`.

## What it means

the run's working directory (--work, FED_WORK, else /var/lib/goat-federation/&lt;partner>) cannot be created or written.

## Why it happens

- the default under /var/lib needs root

## What to do

One line per step or alternative:

```text
goatbuilder federate <partner> --work <a directory you can write>
```
