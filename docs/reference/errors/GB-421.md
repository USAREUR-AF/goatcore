# GB-421: a service the type lists needs an acknowledgement this run was not given

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-421` is printed by `goatbuilder`. The same text offline: `goat explain GB-421` or `goatbuilder explain GB-421`.

## What it means

The machine's type lists a service (`services:`) whose rollout is not cleanly reversible: the component's rollback is declared `none` or `restore-required`, or does not fit its artifact type (ADR 1211). Its deploy proceeds only with a name that accepts that risk, which the deploy ledger row records. join-node and standup pass `--ack` to that deploy, and a run given none is refused before its first phase, rather than at the service's phase after the machine has changed. A dry run plans it and says so. No phase has run.

## Why it happens

- the run was started without --ack

## What to do

One line per step or alternative:

```text
run again with --ack "<your name>"
goatbuilder preflight <component> --env <goatnet> shows the rollout's facts
```
