# GB-212: the host firewall is loosened without a recorded reason

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-212` is printed by `goatbuilder`. The same text offline: `goat explain GB-212` or `goatbuilder explain GB-212`.

## What it means

An override entry widens a baseline rule (more sources, other ports, another interface), or a role input is wider than the profile (goat_host_firewall_mesh_udp_ports not empty, a mesh DNS port other than 5353, a management source broader than goat_host_firewall_management_prefix_floor, or that floor set broader than /24 or /64), and no reason is recorded for that rule. Tightening is free; loosening a named rule needs a reason recorded in the deployment's configuration. Nothing was applied.

## Why it happens

- the entry has no reason: key, or a blank one
- an entry meant to narrow widens instead (an empty sources list means any source)

## What to do

One line per step or alternative:

```text
add reason: "<why this host needs it>" to the entry in goat_host_firewall_override
narrow the rule instead, which needs no reason
```
