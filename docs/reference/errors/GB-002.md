# GB-002: unknown goatnet

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-002` is printed by `goatbuilder`. The same text offline: `goat explain GB-002` or `goatbuilder explain GB-002`.

## What it means

the --env value is not a goatnet key the pins declare. A key is spelled exactly as the pins spell it, underscores included.

## Why it happens

- the goatnet was typed with a hyphen where its key has an underscore

## What to do

One line per step or alternative:

```text
goatbuilder deploy --env <goatnet> …
goatbuilder doctor --all (lists every environment)
```
