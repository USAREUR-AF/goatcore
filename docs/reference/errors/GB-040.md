# GB-040: that directory is not a tutor workspace

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-040` is printed by `goatbuilder`. The same text offline: `goat explain GB-040` or `goatbuilder explain GB-040`.

## What it means

the tutor creates its workspace in an empty or new directory and deletes only a directory that carries its .goatbuilder-tutor marker; it refused to use or delete one that does not.

## Why it happens

- --workspace (or $GOATBUILDER_TUTOR) points at a directory with other files in it

## What to do

One line per step or alternative:

```text
goatbuilder tutor --workspace <an empty or new directory>
unset GOATBUILDER_TUTOR (the default is ~/.goatbuilder/tutor)
```
