# GB-263: a site id cannot name the variables its phases read

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-263` is printed by `goatbuilder`. The same text offline: `goat explain GB-263` or `goatbuilder explain GB-263`.

## What it means

Phase 12 reads the NetBird token from &lt;SITE>_NB_API_TOKEN, named after the site that governs the ACL: the site itself, or a joiner's founder (join_founder_site). That site holds a character a variable name cannot, so the standup stops before any phase.

## Why it happens

- join_founder_site in the site's group_vars holds a space, a quote or another character outside letters, digits, - and _
- the site was named with such a character

## What to do

One line per step or alternative:

```text
set join_founder_site to the founder's site id (letters, digits, - and _)
goatbuilder validate (the site ids goatbuilder.yaml declares)
```
