# GB-069: the rollout preflight cannot run

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-069` is printed by `goatbuilder`. The same text offline: `goat explain GB-069` or `goatbuilder explain GB-069`.

## What it means

preflight reads the component's declared rollout facts from ops/pins/fleet-pins.yaml (owns_state, rollback, restore_from, coupled_with) and the open graduation sets. The component is not in the pins, or the pins could not be read, so there is nothing to grade.

## Why it happens

- the component name is misspelled or not a fleet-pins component key
- ops/pins/fleet-pins.yaml is missing, unreadable, or did not parse
- on a fixture (--mock), declared/artifacts.yaml did not parse

## What to do

One line per step or alternative:

```text
grep -n '^ [a-z].*:' ops/pins/fleet-pins.yaml (the component keys this repository declares)
goatbuilder preflight <component> --env <goatnet> (name the component as its fleet-pins key)
```
