## What it means

A verb runs git, gh, ansible or one of the repository's own steps and stops when it fails. The message is that command's own error output; it names what went wrong.

## Why it happens

- the command's own error, quoted in the message (a network failure, a missing credential, a refused push)

```text
read the quoted output: its tool's own catalog entry may name it (goatbuilder explain '<the line>')

```
