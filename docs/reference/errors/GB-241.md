# GB-241: the environment named is not declared

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-241` is printed by `goatbuilder`. The same text offline: `goat explain GB-241` or `goatbuilder explain GB-241`.

## What it means

A verb was given an environment that goatbuilder.yaml (or goatlite.yaml) does not declare in environments:. Nothing runs against an environment nobody declared.

## Why it happens

- a misspelt environment name
- the environment is declared in another checkout's goatbuilder.yaml

## What to do

One line per step or alternative:

```text
the names declared are listed in the message; pass one of them
add the environment to ops/goatbuilder/goatbuilder.yaml environments:
```
