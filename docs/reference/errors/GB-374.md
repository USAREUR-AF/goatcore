# GB-374: a machine type or platform family file is not valid

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-374` is printed by `goatbuilder`. The same text offline: `goat explain GB-374` or `goatbuilder explain GB-374`.

## What it means

join-node and standup read what a machine converges as from ops/goatbuilder/targets/ and ops/goatbuilder/families/, and a private overlay's own files from ops/goatbuilder/overlay/. One of them is not readable, has an unknown field, names a value or a built-in step this goatbuilder does not have, or repeats a name. The message names the file and why. Nothing ran.

## Why it happens

- a misspelt or unknown field in the file
- an overlay file with the name of a type or family the repository already has
- the file was written for another goatbuilder release

## What to do

One line per step or alternative:

```text
correct the file the message names; ops/goatbuilder/targets/README.md is the format
give an overlay's type a name of its own
```
