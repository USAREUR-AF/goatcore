# GB-077: this checkout's origin is not where release candidates are cut

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-077` is printed by `goatbuilder`. The same text offline: `goat explain GB-077` or `goatbuilder explain GB-077`.

## What it means

the repository that origin names does not run rc-validate.yml, so a tag pushed there is never validated or built where the ladder reads images; the run refuses before the tag (ADR 1173).

## Why it happens

- the checkout is a clone of a mirror or a fork, not the primary repository

## What to do

One line per step or alternative:

```text
git remote get-url origin
run from a checkout whose origin is the primary repository
```
