# GB-384: a target type lists a service its machine cannot have

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-384` is printed by `goatbuilder`. The same text offline: `goat explain GB-384` or `goatbuilder explain GB-384`.

## What it means

A target type's `services:` names components of ops/pins/fleet-pins.yaml, and its machine's build deploys each one. The message names the service and what is missing: the component, the machine's group among the goatnet's members, the pin rendered for that group, or the component's deploy play. A list is a requirement, so it is refused and never skipped; a component the pins declare `absent: true` for the group is skipped. Nothing ran.

## Why it happens

- the type lists a name that is not a component
- the machine's group is not a member group of the goatnet, or goatbuilder pins has not been run since
- the component's play is in another repository, and this tree was not assembled with it

## What to do

One line per step or alternative:

```text
declare the component, its pin and the group in ops/pins/fleet-pins.yaml, then: goatbuilder pins
where the machine must not run it, declare it absent: true with a reason in the component's deviations
```
