## What it means

The peering is declared with two drivers (`drivers: two`): an edge driver that reaches only the edge host and a controller that reaches the core. This phase needs the edge, so the controller stopped before acting and handed it to the edge driver. The stop prints the exact command to run there, the file it writes, and the two commands to run here after it; with -o json the report carries them as the member handoff. It stops as a by-hand stop does (exit 0).

## Why it happens

- the peering's phase needs the edge host, and this machine is the controller
