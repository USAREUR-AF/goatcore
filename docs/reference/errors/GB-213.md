# GB-213: the host firewall would cut the session managing the host

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-213` is printed by `goatbuilder`. The same text offline: `goat explain GB-213` or `goatbuilder explain GB-213`.

## What it means

The rendered ruleset admits no SSH from the source of the session running the play (read from SSH_CONNECTION on the host), so loading it would lock the deployment out. Nothing was applied.

## Why it happens

- goat_host_firewall_management_sources does not hold the address this play connects from
- the override drops ssh-management, narrows its sources past this address, or binds it to another interface
- SSH listens on another port than goat_host_firewall_ssh_port
- the session's source could not be read, so the check could not run

## What to do

One line per step or alternative:

```text
add the controller's address to goat_host_firewall_management_sources
run the play from a declared management source
```
