# GB-386: the served release is older, so --force does not install it

Generated from `ops/errors/catalog.yaml` by `ops/ci/check-error-catalog.py --write`; do not edit here. `GB-386` is printed by `goatbuilder`. The same text offline: `goat explain GB-386` or `goatbuilder explain GB-386`.

## What it means

`goatbuilder update --force` reinstalls the version this binary already is. The surface serves a version that is older than this binary, or one that does not compare as a version, so installing it would go back. That takes its own flag, `--allow-downgrade`. Nothing was downloaded or installed.

## Why it happens

- the goatnet's get surface still serves an older release than the one installed here
- the binary was installed from a newer release or built from source

## What to do

One line per step or alternative:

```text
goatbuilder update --allow-downgrade (to install the served release on purpose)
goatbuilder update --check (to compare the running and served versions)
```
