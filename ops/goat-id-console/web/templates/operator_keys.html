An operator key makes your Portal admin actions attributable to {{.OperatorKeyHandle}} instead of to a shared credential. It is not the vp_ key ordinary members paste into the Portal, and it is not in your bundle or your welcome email.

It is for admins. Approving one hands over the Portal's admin API and this console's machine API for every organisation, slot and person on the goatnet, so the console will not record a request from a login that holds no admin group.

Requesting records the ask and grants nothing. An admin approves, and at that moment the key becomes live — there is no install step afterwards. You collect it here, once.

Operator keys

Each key attributes one person's Portal admin actions to their name. Approving is the grant: the key is written to the directory the Portal reads, and the Portal picks it up on its next reload. There is no installer step to follow — unlike an SSH key, approved here means live.

You are deciding about the person and the work, not about the request being well-formed — and never about your own: a request is decided by a different admin. Revoking removes the file; the Portal stops accepting the key on its next reload.

Looking for your own first operator key, not somebody else's request? This page is the decide queue — go to your operator key instead.
