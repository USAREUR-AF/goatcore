Connectivity Probe

Five-layer reachability check: DNS → TCP → TLS → cert-chain validates against our root CA → your client cert's URI-SAN matches your declared prefix. The portal does NOT initiate a probe to your machine; you run the script locally and paste the JSON output back. Read the script before running it — it does only reads, no network listeners, no data transmitted to the portal.

Step 1 — Configure

Without a prefix or cert path, layer 5 is skipped (the rest of the probe still runs). You can also pass --prefix and --cert directly on the command line when invoking the script.

Step 2 — Read the script

This is what the script does. Skim it; nothing here writes to disk except a temp file for the root-CA download.

Step 3 — Run it

On the host that's supposed to reach the router, run the script. It echoes a single-line JSON object to stdout. Copy that whole line.

Linux + macOS: ready to go. Windows: run it under WSL. Any script that emits the same JSON shape will paste back fine if you want to write a native PowerShell version.
