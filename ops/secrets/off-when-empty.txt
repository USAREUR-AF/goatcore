# off-when-empty.txt — environment names whose EMPTY value is a valid setting that
# turns one outbound channel off (docs/design/pluggable-dependencies.md row 16).
#
# The deploy presence check (ops/scripts/deploy-secrets-needed.py) and its mirror in
# `goatbuilder doctor` (crates/goatbuilder/src/doctor.rs) never report these as
# MISSING: a goatnet with no PagerDuty, Slack or mail account deploys, and its
# alerts stay on its own ntfy and Grafana. Every role that reads them treats empty
# as off; tests/test_alert_channels_off_when_empty.py proves both, and fails if a
# role starts to require one.
#
# One name per line, then what an empty value turns off.
PAGERDUTY_INTEGRATION_KEY       Alertmanager critical route to PagerDuty
PAGERDUTY_INTEGRATION_KEY_EU    Alertmanager critical route to PagerDuty (EU service)
SLACK_ALERT_WEBHOOK_URL         Alertmanager warning route to Slack
ALERT_SMTP_SMARTHOST            Alertmanager warning e-mail (the relay)
ALERT_SMTP_USER                 Alertmanager warning e-mail (relay login)
ALERT_SMTP_PASS                 Alertmanager warning e-mail (relay login)
ALERT_EMAIL_DIGEST_RECIPIENTS   Alertmanager warning e-mail (who gets it)
